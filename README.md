I build web applications for real businesses — accounting, electronic invoicing and appointment booking — and interactive tools that make math visible for students.

- 💼 **Expertak** — accounting platform for firms that manage dozens of client companies: imports the DIAN's bulk Excel exports, builds consolidated reports and issues DIAN electronic invoices (CUFE, preflight checks, emission). *FastAPI · Svelte · Supabase.*
- ✂️ **Turno** — booking app for barbershops and beauty salons: clients book from their phone without an account, barbers run their day from a live calendar. Bilingual. *React · Supabase.*
- 🧮 **STEM tools** — **SólidoLab** (3D solids, surface area and volume) and the **Fraction Visualizer**, built for my math classes.
- 🧪 **Physics background** — thesis on Raman spectroscopy of cerium-doped ZnO, with data analysis in MATLAB.
